# AquaShift — Green Shift Hacks 2026

A functional water-saving decision tool, with editable intervention model, actual meter log, habits, and CSV export.

**Live demo:** https://aquashift-green-shift-hacks-2026.vercel.app

The complete portable source ZIP and `core.mjs` source were generated for this submission. The web demo is a self-contained static HTML document with transparent JavaScript modeling code.

**Methods:** 30.44 days/month, two brushing sessions daily, 0.25 mL per tap drip. No measured impact or causality is claimed.

**Technology:** HTML, CSS, JavaScript, Node test runner.
